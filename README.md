# 心理学统计 Agent

**面向心理学研究的中文桌面统计与科研构思工作台。** 从问卷筛选、路径规划到统计分析和报告导出，可直接操作界面，也可配置自己的 AI API，通过对话完成设置与核对。

## 快速开始

1. **安装软件。** 下载并运行 `Psychology-Statistics-Agent-0.8.0-Setup.exe`，安装后打开“心理学统计agent”。
2. **配置 AI。** 在“模型服务设置”填写主力服务地址、API Key、模型 ID 和接口类型，并确认数据发送范围。支持 Responses 和兼容 Chat Completions 的服务，模型必须支持工具调用；请先测试连接。**检测模型可选，默认关闭**，可与主力共用服务或单独配置。
3. **导入并分析。** 通过“＋”添加数据或问卷筛选规则附件。选择“元分析”或“问卷”；问卷页负责筛选与计分，完成后自行进入中介调节、异质性、网络等独立页面，确认沿用哪份数据。
4. **导出或继续构思。** 导出 Excel、Word 与适用的图片。需要科研构思时，点击右上角按钮，选择一份筛选后的数据，手动输入检索关键词，再开始任务。

例如，筛选时可以对 AI 说：

> 一行一名受访者，ID 是编号。Q1、Q2、Q3 构成压力均分，Q2 反向，范围为 1–5 分，至少回答两题。排除 Duration 小于 120 秒的记录。请检查我是否还遗漏了什么。

软件不会自行猜测题项属于哪份量表。筛选和补充核对步骤可跳过；实际分析仍需明确必要的变量与参数。未配置 AI 时，也可通过界面和配置项完成本地分析。

## 统计分析工作区

| 入口 | 主要功能与交互 |
|---|---|
| 元分析 | 常规与三水平模型，r / d / g / OR 效应量准备，调节分析、发表偏倚诊断、逐一剔除与森林图 |
| 问卷筛选 | 指定行列、题项归属、反向计分、计分和排除规则；保留处理记录，步骤可选 |
| 中介调节 | 选择变量后在可视化画布安排路径；左键添加、右键删除，调节箭头指向被调节的路径；估计间接及条件间接效应，可选 Bootstrap 区间 |
| 异质性 | 潜在剖面（LPA）、潜在类别（LCA）、网络树；网络树分别指定节点变量与分裂变量，可选分组继续后续分析 |
| 网络分析 | 选择题项、分量表或总分节点；估计 GGM（EBICglasso）/ Ising 网络、强度与预期影响（EI）、case-dropping CS，以及适用的独立两组网络比较 |
| DAG | HC、Tabu、MMHC、PC、GES、FCI；展示 DAG / CPDAG / PAG、方向不确定性与不同算法的边差异 |
| 干预 | 确认假设后计算适用 CPDAG 的 IDA；NIRApost / GGMNIRA 指定干预变量、结果范围与强度，导出长时计算任务，再导入实际结果解读 |
| 机器学习 | 明确预测目标、可用特征和任务类型；随机森林、线性/二分类逻辑基线、保留测试集及可选分组划分 |

各分析都有独立页面。进入下一步时显示当前数据来源与版本，由使用者决定是否沿用或跳过；切换分组和数据版本后，相关旧拟合不能冒充新数据的结果。三个工作区可调整宽度，右侧科研构思默认隐藏，可通过右上角按钮显示。

### 完整报告与内嵌科研绘图

- **Excel 和 Word**：导出实际结果、参数、方法限制与数据处理审计；适用分析包含区间、分组成员、预测结果和矩阵标签。
- **科研图片**：从实际计算结果生成固定模板图，可调整中文标签、标题、尺寸和配色；绘图工作室支持 300 / 600 DPI PNG，以及矢量 SVG / PDF。
- **可追溯文件**：保留当前分析数据、配置、绘图数据与 JSON 审计，旧数据版本单独标明。

NIRApost / GGMNIRA 导出独立 R 脚本和任务清单，在外部环境计算，结果写入脚本旁的 `results/`。将其中的 `statistics.csv` 导回软件解读，可附加外部图片。长时模拟在外部运行，避免计算过程中反复调用模型；具体依赖、文件和限制见[干预长时任务说明](agent/desktop/README.zh-CN.md#干预的长时任务)。

## 多智能体科研构思

输入为 **筛选后的数据＋手动检索关键词**，可补充研究问题。任务固定绑定所选筛选后数据快照，切换左侧文件、分组或分析入口不会改变已启动任务的数据来源；原始导入表或跳过筛选的数据不能直接作为该任务的输入。

六类角色使用独立上下文与不同工具权限：

1. **调度员**：维护计划，决定角色委派与修订顺序。
2. **缺口发现**：依据检索证据识别已有研究的限制与待解决问题。
3. **跨领域创新**：从相关或类比研究中形成候选方案。
4. **方案审阅**：检查证据、数据适配、可行性和本次检索范围内的新颖性。
5. **论文阅读**：独立处理一篇材料，返回目标摘要，并区分全文、摘要与生成注释。
6. **报告撰写**：汇总候选、审阅意见、引用和局限，生成可核查的研究方案。

**全部角色使用你配置的 API。** 启用可选检测模型时，方案审阅使用检测 API，其余角色使用主力 API。可设置调用预算、停止任务并保留已有阶段产物；角色必须通过固定工具读取资料、保存产物，不能任意执行代码。

文献工具支持 Crossref、Europe PMC 与 arXiv 检索，结果可继续分页；保留真实书目、来源编号、阅读摘要、证据等级与工具记录。可选导入 [Svalbard Idea Vault](https://huggingface.co/datasets/Jerry999/SvalbardIdeaVault) 的 JSONL / JSONL.ZST 分片，建立本机 SQLite FTS5 / BM25 索引。安装包不内置完整语料，其生成注释不等于原论文全文。

核心角色与专业工具设计参照 [IdeaScientist](https://github.com/jiarui-liu/IdeaScientist) 独立实现。软件使用自己的模型服务接口，没有使用作者训练的模型权重，也没有复现其强化学习训练或论文评测成绩。研究方案独立导出 Excel、Word、JSON 和 CSV，绑定该次任务的筛选后数据与证据。

## 数据发送范围

**本地统计计算不代表所有信息都不离开本机。** 开启 AI 前，请先处理身份信息，并核对模型设置中的发送范围：

| 场景 | 发送到哪里、包含什么 |
|---|---|
| 本地统计 | 完整数据在本机计算；使用本地分析功能本身不需要将原表上传给模型 |
| 主分析 AI 对话 | 对话、列名、前六行预览、规则附件文字、界面状态及分析摘要/工具结果会发送到选定的主力服务；启用检测后，检测服务也接收核对所需的信息 |
| 科研构思 | 发送所选筛选后快照的变量与描述统计、方法适配及工具返回的探索性摘要、关键词、研究问题与检索证据；该任务不接收原始表、排除记录或其他快照 |
| 在线文献检索 | 向相应文献来源发送检索词；角色可能据研究缺口衍生新关键词 |

密钥通过 Windows 加密保存。实际外发与服务方的数据处理规则有关，使用前请阅读所选 API 服务条款。[完整使用说明](agent/desktop/README.zh-CN.md)列出更详细的数据范围与工作流。

## 方法与版本限制

- **测试版范围**：主分析工作区退出前需导出；科研构思快照和上次任务可在本机保留。51 项软件测试通过，已用合成数据检查打包程序、中文路径安装、筛选、元分析、HC DAG、绘图与报告导出；API 流程使用模拟服务测试。这些检查不等于所有模型、真实服务或研究设计均已验证。
- **中介调节**：当前为数值型观测变量的无环递归路径，复杂潜变量、纵向和多层模型需另行扩展；横断面间接效应不能确认因果中介。
- **异质性与机器学习**：类别与分裂不能仅凭单一拟合指标定论；网络树检验相关/协方差异质性。机器学习采用固定参数和单次保留测试集，正式研究应增加重复或外部验证。
- **网络、DAG 与 IDA**：网络边是条件关联，搜索出的箭头不是已证实的因果方向。标准 IDA 要求适用的连续数据 CPDAG 及线性高斯、无未测混淆等假设；FCI 的 PAG 不能直接进入本版标准 IDA。IDA 候选效应范围不是置信区间。
- **模拟干预**：本版以对应网络 EI 的 CS > 0.25 作为最低流程门槛，指标、节点与数据版本必须匹配；阈值不证明真实干预有效。GGMNIRA 在本版标记为尚未正式发表，使用前请另行核对原文与实现版本。
- **科研构思**：只在实际检索范围内审阅新颖性；未取得全文时保留实际证据等级。AI 建议与检索条数都不等于完成系统综述，也不构成统计、因果或首创性保证。
