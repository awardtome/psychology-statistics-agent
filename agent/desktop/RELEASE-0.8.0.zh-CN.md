# 心理学统计 agent 0.8.0

Windows 64 位中文桌面测试版，内置本地计算环境。日常使用无需另行安装 R、RStudio 或 Node。

## 下载和开始使用

1. 下载本页附件 `Psychology-Statistics-Agent-0.8.0-Setup.exe`，运行安装后打开“心理学统计agent”。
2. 在“模型服务设置”配置主力 API 和模型 ID，确认数据发送范围。支持 Responses 与兼容 Chat Completions 的服务，包括支持工具调用的第三方模型；检测模型可选，默认关闭。
3. 选择“元分析”或“问卷”。问卷页面只负责筛选和计分，后续分析通过各自独立页面进入。
4. 科研构思：应用问卷筛选规则后，打开右上角“科研构思”，选择一份筛选后的数据，手动填写检索关键词，再开始任务。

完整说明：[中文使用说明](https://github.com/awardtome/psychology-statistics-agent/blob/main/agent/desktop/README.zh-CN.md)。开发源码在 `agent/desktop`；本页附件 `Psychology-Statistics-Agent-0.8.0-Source.zip` 为本独立仓库的完整交付源码。

## 功能与更新

- 元分析、问卷筛选、中介调节路径画布、潜在剖面/潜在类别/网络树、GGM/Ising 网络、DAG、干预方案与机器学习。
- 三个窗口可调宽；右侧科研构思默认隐藏。中介路径左键添加、右键删除，调节箭头指向被调节路径。
- 内嵌固定模板科研绘图，读取实际分析结果；分析导出完整 Excel 和 Word，适用方法同时导出科研图片。
- 科研构思采用“筛选后数据＋手动关键词”。任务固定绑定所选快照，切换文件、分组或后续数据不会改变已启动任务的数据来源。
- 参照 [IdeaScientist](https://github.com/jiarui-liu/IdeaScientist) 的核心角色与工具思路独立实现：调度、缺口发现、跨领域创新、方案审阅、论文阅读、报告撰写。所有角色使用使用者配置的 API，未使用作者训练的模型或复现强化学习训练及论文评测成绩。
- 真实文献检索支持继续分页；正文、摘要和生成注释分级标记，保留来源编号与阅读摘要。可选导入 [Svalbard Idea Vault](https://huggingface.co/datasets/Jerry999/SvalbardIdeaVault) 的 JSONL/JSONL.ZST 分片，建立本机 FTS5/BM25 索引，安装包不内置完整数据库。
- 科研构思可独立停止，已有产物保留；筛选时缓存数据摘要，构思不需等待左侧统计计算。科研构思独立导出 Excel、Word、JSON 和 CSV。

## 验证与适用范围

- 发布前重新运行软件测试：51 项通过，0 项失败。
- 已验证打包后的程序与中文路径下实际安装的程序，使用合成数据完成元分析（18 项研究、36 个效应）、问卷筛选（237 条记录）、HC DAG、科研绘图和报告导出。
- 已验证筛选快照的持久化、哈希校验、只读计算、版本绑定，以及拒绝原始数据或跳过筛选的数据直接进入科研构思。
- API 流程使用本机模拟服务测试，未上传真实受访者数据或调用付费模型；不同第三方服务的实际兼容性需使用其真实模型 ID 和工具调用接口。

安装包为未签名测试版。软件测试不代表所有统计设计均已获得方法学验证；横断面关联、DAG 与模拟干预不能自动解释为真实因果效果。主分析工作区退出前需导出；科研构思快照和上次任务可在本机保留。NIRApost/GGMNIRA 长时任务按使用说明导出 R 代码，在外部环境运行后返回结果解读。
