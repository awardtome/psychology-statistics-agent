# 心理学统计agent 0.3.0 更新与检查记录

检查日期：2026-10-03。此版本在原有元分析和问卷工作流上修复状态与报告问题，新增内嵌科研绘图。

## 已修复的问题

1. 点击“跳过整个筛选步骤”仍应用之前的筛选、缺失码和计分设置。现在从原表恢复，仅保留明确的行列方向和变量说明。
2. 新数据继承旧 source record 编号，数据分支留下旧方案或确认。现在统一重置，并保留可导出的历史分析。
3. 重算上游网络或 DAG 后，旧 IDA 结果和人工假设确认仍可被沿用。现在清理依赖结果并要求核对新图。
4. 返回外部 CS 后，界面和 AI 上下文未及时同步。现在以计算引擎的最新状态为准。
5. 外部干预表被直接冠以当前样本量和数据版本。现在明确标记未知来源，表格行数与受访者数分开。
6. Word 漏掉类别数、熵、IDA 范围等摘要；矩阵丢失行列标签；JSON 截断数值精度。现在补齐并导出各版本输入和审计。
7. 部分问卷异步操作提前解除忙碌锁。现在等待完成后解锁；引擎超时后停止，避免迟到结果写入。
8. 模型看到截取的大表却未被告知截取范围，部分工具返回本地图片路径。现在统一生成模型上下文，去除图片/路径并标注总行数和预览行数。
9. 大型分析文件难以维护。现在按统计方法拆分，工作区状态重置、模型上下文和绘图模板分别管理。

10. CSV 数值文本不能进入问卷计算，文字分组不能进入网络树。现在仅在工作副本解析明确数值并记录审计，前导零/长整数编号保留文本；声明缺失码后重新检查数值类型。指定的文字分裂变量按类别处理。
11. 选择多工作表文件期间可能残留上一份数据。现在等待选表时清空可计算状态，防止误用旧文件。

## 内嵌科研绘图

界面底部“科研绘图工作室”与 AI 的 render_research_figure 工具使用同一套本地模板。图的数据来自已经完成的分析，不接受 AI 编造的统计数值或任意代码。

提供系数/区间、LPA、LCA、网络树、GGM/Ising 网络、EI、DAG/CPDAG/PAG、IDA、特征重要性和森林图。支持中文、色觉友好/黑白/低饱和配色、明确的画幅和 300–600 DPI。导出 PNG、SVG、PDF，Excel 保存实际绘图数据和设置，Word 保存图和来源说明。图中的 PAG 圆圈/箭头与节点标签分别保留，不将未定向边改成有向边。

网络树保留方法包的原生结构和标签/配色；其他模板按支持的设置绘制。投稿前仍须核对目标期刊的图幅、图注、字体和报告规范。

## 验证范围

- 19 项 Node 测试：模型调用、分享范围、状态重置、人工确认、上下文截取及绘图工具接口。
- 实际计算回归：13 个分析任务，覆盖中介、LPA/LCA、网络树、GGM/Ising、HC/PC/GES/FCI、IDA、回归/分类。
- 实际文件与衔接：CSV 类型、前导零/长整数编号、文本缺失码、实际分裂网络树，以及 200 人子组继续网络分析。
- 专门回归：跳过筛选、新数据编号、依赖结果失效、外部来源、审计精度及历史报告。
- 科研绘图：11 个问卷图示例和元分析森林图；三种格式及报告整合。PDF 确认为矢量，PNG 检查像素尺寸和 DPI，中文与图结构经过视觉检查。
- 模型服务使用本机模拟 Responses/Chat 接口，不调用付费 API；所有统计示例均为合成数据。
- 安装包另附 installer-verification.json，记录实际安装后运行的结果。
