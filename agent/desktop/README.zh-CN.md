# 心理学统计agent 0.8.0

这是可直接安装的 Windows 64 位桌面软件。安装包包含本地计算环境，日常使用不需要另行安装 R、RStudio、Node 或浏览器服务。

## 安装和开始使用

运行 Psychology-Statistics-Agent-0.8.0-Setup.exe，选择安装目录，打开“心理学统计agent”。这是未签名的测试版安装包。

首页有“元分析”和“问卷”两个入口。先通过“模型服务设置”填写主力模型的模型 ID，确认数据发送范围，即可测试主力连接并使用 AI。检测模型是可选功能，默认关闭；只有勾选“启用检测模型（可选）”才需要填写并调用检测模型。它可共用主力服务的地址、接口和密钥，也可单独配置另一个服务。关闭检测会保留配置，不再发送检测请求。支持 OpenAI Responses 与兼容 Chat Completions 服务；本机模型服务可用 localhost HTTP，远程地址要求 HTTPS。密钥由 Windows 加密保存。

主分析工作区在本次会话中保留。退出前请导出完整分析报告；模型设置长期保存，主分析重新打开后需要重新导入数据。科研构思使用的筛选后快照和阶段产物独立保存在本机，重新打开仍能选择快照并查看上次任务。

完整原始表在本机计算。开启 AI 对话后，会发送对话、列名、前六行预览、规则附件文字、界面状态和分析摘要/工具结果到你选定的主力服务；只有启用检测后，检测服务才接收核对所需的信息。本地计算不代表所有信息都不离开本机，请事先处理身份信息并核对发送范围。科研构思发送所选筛选后快照的变量、描述统计、方法适配与工具返回的探索性摘要、手动关键词、研究问题和检索证据，不把原始表、排除记录或其他快照送入该任务。在线文献工具向 Crossref、Europe PMC、arXiv 发送检索词，角色可据研究缺口衍生新的同领域或跨领域关键词。

## 0.8.0 科研构思更新

右上角“科研构思”替换原文献辅助，默认隐藏，点击可显示，窗口仍可拉伸。输入方式是“筛选后数据＋手动检索关键词”。先在问卷页面点击“应用当前计分和筛选规则”，软件会保存一份独立快照；再点“筛选后的数据”或右上角打开科研构思，选择具体快照，填写关键词。研究问题、列的含义与研究设计可补充。跳过整个筛选不会保存科研构思快照；需要不排除记录时，可以清空筛选规则并明确应用，以保留来源记录。

任务开始后固定绑定所选快照。切换左侧文件、筛选版本、分析入口或异质性分组都不会改变这次科研构思的数据；右侧下拉框改选其他快照时，已有产物仍显示其真实来源，只有新任务才使用新选择。本地数据查看和探索性相关工具均校验快照编号与文件哈希，没有任意文件读取或代码执行工具。

筛选时会缓存并校验这份快照的数据摘要，右侧开始构思无需等待左侧长时间统计计算。额外的探索性相关在本地计算引擎中排队；停止科研构思立即停止后续 API 请求，保留已有产物，不会中断左侧正在运行的统计分析。

对照 [IdeaScientist 核心实现](https://github.com/jiarui-liu/IdeaScientist) 独立实现角色与权限设计：调度员维护 plan.md 并决定委派；缺口发现保存 gaps.md；跨领域创新保存 candidates.md；方案审阅保存 scores.md；报告撰写保存 report.json；论文阅读只在独立上下文里接收一篇正文并返回摘要。调度员不能检索或读论文，其他角色不能直接接触全文。角色必须保存有效产物；引用编号必须来自实际检索并经阅读处理，产物记录真实快照编号、行数和已有变量。角色可修订候选并重新审阅，最多三次同角色委派，调用预算40/60/100次可选，随时停止会保留已生成内容。

所有角色使用你配置的主力 API；开启可选检测模型时，方案审阅角色使用检测 API，其余角色仍用主力 API。支持 Responses 和兼容 Chat Completions，第三方模型需要支持工具调用。采用的是其核心工作流和专业工具思路，没有复制其训练权重、运行强化学习训练或复现论文的评测成绩。未调用付费服务进行安装验证。

“文献证据”显示每条真实书目、正文/摘要/生成注释的证据等级和独立阅读摘要；每条检索可继续加载下一页，支持超过首批20条。新增文献不会自动被宣称已用于旧方案，需重新运行研究任务。开放全文获取失败时明确保留摘要或书目等级，不会假装读到全文。只读书目不能用于支持方法与结果。新颖性只在本次实际检索范围内审阅；方案中的统计、实验与因果假设仍须研究者验证。

可选导入 [Svalbard Idea Vault](https://huggingface.co/datasets/Jerry999/SvalbardIdeaVault) 下载的 `.jsonl` / `.jsonl.zst` 分片，建立本机 FTS5/BM25 索引，无需另装嵌入模型。分片可多选、可停止、重复记录按 arXiv 编号去重；大型语料需要额外磁盘空间。安装包不内置或自动下载整个数据集；未导入仍可在线检索。数据集的 problem_definition、intuition、proposal_masked 是生成的结果遮蔽注释（CC BY 4.0，来源署名见本段链接），不是原论文；界面、阅读工具及报告会区分注释与原文，优先核对真实开放正文。原仓库采用 CC BY-NC 4.0，本软件新模块为独立实现，无论文仓库源码或模型权重复制。

“研究方案 / 阶段产物 / 文献证据 / 工具记录”分别供阅读与核查。“导出完整 Excel 与 Word 报告”导出该任务绑定的筛选后数据、描述统计、每个角色产物、阅读摘要、检索记录和工具审计，另附 JSON/CSV；不加入当前左侧工作区的原表与排除记录。未完成或停止的任务在报告中标明状态。分析模块的原有 Excel、Word、科研图片导出功能继续保留。

## 问卷工作区

“问卷”入口只显示筛选与计分界面。点击对话输入区的“＋ → 添加分析数据”，或侧栏的导入按钮，添加 CSV、TSV、XLSX 或 XLS，最多 30 MB。对话区显示当前文件；每次导入新表替换当前工作区，本版一次分析一份表。多个工作表由使用者明确选择，选择期间不会沿用旧数据计算。CSV/TSV 的明确数值文本只在工作副本中解析，原表不变；前导零与长整数编号保留文本，转换记录进入审计。可先加载合成示例体验；示例不代表实际研究发现。

在对话里说明：

- 一行一个受访者，还是一列一个受访者；如果变量在行上，指出题号/变量名所在列。
- 哪些题项构成哪些变量、总分或分量表，变量的理论含义。
- 反向题、实际计分上下限、均分/和分/折算和分以及最少答题数。
- 缺失代码、纳入范围、作答时间、注意力题、同质作答、重复编号等筛选规则。

软件不猜量表，不擅自添加排除规则。每次从原表重算，避免重复反向计分。越界题项会使对应量表分数缺失并进入审计，不擅自排除受访者。计分、筛选和遗漏补充检查都能跳过。筛选后仍留在问卷界面，不自动切换分析。当前筛选数据会保留，由使用者自行点击问卷下面的中介调节、异质性、网络、DAG、干预或机器学习按钮。

示例对话：“一行一个人，ID 是编号。Q1、Q2、Q3 构成压力均分，Q2 反向，范围 1–5，至少答两题。排除 Duration 小于 120 秒的记录。检查还有什么遗漏。”

## 分析入口

| 入口 | 当前实际实现 | 使用者需要说明 |
|---|---|---|
| 中介调节 | lavaan 递归路径、指定间接路径、中心化交互项、可选 bootstrap 区间 | 变量与每条路径；协变量以路径形式声明 |
| 异质性 | LPA 高斯混合模型与各类均值、LCA 条件概率、多指标相关网络树 | 指标、类别数范围；网络树的分裂变量 |
| 网络 | GGM / Ising、强度与 EI、case-dropping CS、独立两组标签置换比较 | 节点层次与变量、相关类型、分组和重抽样次数 |
| DAG | 默认 HC；Tabu、MMHC、PC、GES、FCI；等价图及算法边差异 | 节点、连续/分类类型；可选禁止路径 |
| 干预 | 当前连续 CPDAG 的 IDA；NIRApost / GGMNIRA 独立 R 任务导出和结果导入 | IDA 暴露/结局及假设确认；模拟算法适配 |
| 机器学习 | 随机森林、线性/二分类逻辑基线；保留测试集；可选按受访者/机构分组划分 | 目标、预测时可用特征、回归或分类 |

每个按钮立即打开相应的独立页面，可直接选择变量和方法，也可跟 AI 说明。尚未导入数据时也可以先打开页面了解流程。点击“问卷”或“返回问卷筛选”只回到筛选页；不会丢失同一数据版本的分析结果。实际计算前确认使用这份筛选数据。每个入口都可让 AI 核对遗漏，也可跳过补充问答。实际变量、路径与必要算法输入不能由软件捏造。高级配置仅用于核对或不接模型时直接配置，不要求使用者写代码。

异质性分析保存每条记录的类别/树节点编号。可以选择整体筛选后的数据或一个分组继续网络分析；改变数据版本会使旧网络与 DAG 失效，旧结果保留在报告记录中。进入网络、DAG、干预之前会显示当前数据来源、版本和有效样本，并让你选择进入或跳过。

标准网络树检验相关/协方差异质性，不是直接检验 Ising 参数。网络边是条件关联；HC 选定的 DAG 与 CPDAG 方向不确定性分别报告。FCI 的 PAG 保留圆圈、箭头、尾端标记，不能直接送入标准 IDA。IDA 的候选效应范围不是置信区间，依赖线性高斯、无未测混淆、无环和忠实性假设。

中介调节支持声明 conditionalIndirect 的路径、调节变量和调节值，计算条件间接效应及区间；未指定调节值时使用原量尺均值及 ±1 SD。复杂潜变量测量模型、纵向、多层或抽样设计需要另外扩展并验证。LPA 默认标准化及等方差对角 EEI 模型，类别不能仅按 BIC 定论。机器学习默认固定参数及单次保留测试集，森林同时报告训练 OOB；正式研究应做重复或外部验证。

## 干预的长时任务

使用者指定的最低门槛为对应网络 **EI 的 CS > 0.25**。未计算时可回网络入口开启 case-dropping，或返回同一节点和数据版本的外部 EI CS；外部报告会明确标注未经本软件核实。CS 指标不能混用，最低门槛不证明因果或真实干预有效。

Ising 对应 NIRApost；GGM 对应 GGMNIRA。GGMNIRA **尚未正式发表，已有预印本**，界面要求使用者确认此状态。NIRApost 导出任务包含调节前提检查、模拟、置换和重复模拟稳定性；发现调节证据时停止固定边权模拟。

点击导出后得到独立 .R 脚本、network-data.csv、网络拟合与任务清单。在 RStudio Source 脚本，或用 Rscript 执行。脚本只在使用者自己的 R 环境中运行长时任务；这一步需要外部 R 环境，与软件日常本地分析区分开。依赖不存在时，脚本会提示/安装所需方法包。

输出在脚本旁 **results/**，包含 statistics.csv、完整 Excel、Word、300 DPI PNG、PDF 和完整 R 对象。外部结果的样本量、来源版本与节点不会自动套用当前数据；未核实的来源会明确标记，需结合任务清单核对。把 statistics.csv 通过“导入外部实际结果”交回软件解读，可附加外部图片。独立运行避免长时计算过程中逐轮请求 AI 浪费 token。结果为网络模拟，不能写成真实治疗效应。

方法实现来源：[NIRApost](https://github.com/kingfly51/NIRA_post)、[GGMNIRA](https://github.com/ywu6888/GGMNIRA)、[GGMNIRA 预印本](https://arxiv.org/abs/2607.00915)。

## 完整报告与科研构思侧栏

所有入口均导出 **完整分析结果.xlsx** 与 **完整分析报告.docx**，可出图的方法另附 PNG，并把图插入 Word。Excel 包含原表、当前数据、排除记录、参数、区间、分组成员、预测结果、配置与方法审计；Word 包含实际结果表、图、方法局限和筛选/计分记录。同时保留 analysis-audit.json 和当前分析数据.csv。旧数据版本的分析在报告中独立标记，Excel 另存各版本的输入数据和处理审计。Word 包含熵、类别数、拟合指标、IDA 效应范围等摘要，矩阵保留行列标签，JSON 审计保留完整数值精度。

右侧科研构思可以与本地分析同时使用，以所选筛选后快照和手动关键词为输入，多角色检索并形成研究方案。文献证据支持分页、稳定来源编号、独立阅读摘要与证据等级；总数不代表全部与研究问题相关，也不代表已完成系统综述。完整科研构思报告通过右侧独立按钮导出，保证报告数据与任务绑定一致。具体使用与 Svalbard 导入见前面的 0.8.0 更新介绍。

## 开发和验证

源码在 agent/desktop。npm ci 后，Electron 44 需要 npm exec install-electron。以授权的 R 开发会话设置 agent_repository 为本独立仓库根目录，并 source scripts/dependency-manifest.R，再运行 python scripts/prepare-runtime.py --r-home 你的Windows-R安装目录；构建所需的元分析源码位于 vendor/meta3level。运行 npm test、scripts/smoke-agent.cjs、scripts/smoke-psych.cjs 和 scripts/smoke-report.cjs，然后 npm run build。安装包测试使用 scripts/smoke-installer.cjs。

AI 工具只调用白名单方法和结构化配置，模型不能执行任意 R/系统代码。测试使用合成数据和本机模拟模型服务，没有调用付费模型或上传真实受访者数据。统计与软件可运行性测试不等同于所有研究设计均已获得方法学验证。

## 0.3.0 内嵌科研绘图

分析工作台底部的“科研绘图工作室”与 AI 的 render_research_figure 工具共用本地绘图引擎。只从已完成的实际分析读取数值，不让模型编造点估计或随意执行绘图代码。

支持系数与 95% 区间、LPA 剖面、LCA 条件概率、网络树、GGM/Ising 网络、EI 中心性、DAG/CPDAG/PAG、IDA 可能效应、机器学习特征重要性以及元分析森林图。选“自动匹配”即可使用当前结果对应的模板。

可调整标题、轴标题、中文变量标签、色觉友好/黑白/低饱和配色、4–12 英寸宽度、3–12 英寸高度、300/600 DPI。可在对话中说：“用内嵌科研绘图工具画当前 GGM 网络，X 标成压力、Y 标成焦虑，使用黑白配色，7×5 英寸，600 DPI。”AI 会调用同一个固定模板工具。

每次生成保留一个图版本。导出完整报告时得到科研图 PNG、SVG、PDF、Excel 内的实际绘图数据和设置，以及 Word 内的图和来源说明。SVG/PDF 为矢量，PNG 为明确印刷分辨率。网络树保留方法包原生树结构和节点图，变量标签与配色沿用拟合对象，标题保存在报告中。投稿前仍需按目标期刊规范核对字体、尺寸和图注。

本版尚未加入任意上传表格的通用作图、科研结果图的任意拖拽编辑或项目保存/恢复；中介调节规划画布支持变量拖动布局，科研绘图入口服务于软件已有的分析结果。

## 0.5.0 要求核对与重构

干预入口新增“独立模拟方案”，也可直接告诉 AI。必须主动指定干预变量、结果范围、强度；NIRApost 还需选择阈值升高/降低。默认重复 1000 次，可以调整为 1–5000；少量仅用于调试。不会默认为所有节点干预，也不会删除其他网络节点来冒充目标选择。

- NIRApost：每次分别改变一个指定节点的阈值，强度以完整网络阈值分布的 SD 为单位；评估整个网络或指定结果节点的和。如果目标属于结果集合，包含它本身的变化。先对完整网络做调节检查；发现证据则停止。重复稳定性、置换检验及区间反映固定拟合参数下的 Monte Carlo 不确定性，不是原始样本抽样推断。
- GGMNIRA：显式正整数操作强度；主分析和 KL 稳定性使用相同强度、结果范围和相关估计。可报告整网 KL 或指定结果集合的边际 KL，后者要求目标与结果集合分开。KL 只表示分布变化幅度。导出时保留完整网络，仅筛出指定目标的统计表与图；KL CS 的范围是对应结果范围的全部候选节点。
- 导出的主脚本将长时计算留在使用者自己的 R 环境中；首次运行按固定 GitHub 修订安装方法包及依赖，需要网络和可用的 R 包安装环境。所有结果集中于 results/ 下每次新建的 run-时间戳目录，重跑不会混入上次成功或失败的文件。部分外部依赖可能另有系统安装要求。
- 修复分组切换：选择一组后仍可选择其他组或恢复筛选后的整表；显示来源版本，每次切换清除旧拟合。重新筛选则清除旧分组。
- 修正 LPA/LCA 类别数（1–8）、网络稳定性次数（0 或 50–2500）与置换次数（20–1000）的界面范围。PC/GES/FCI 明示当前不支持禁止方向约束。
- 结果区展示实际计算方案，提示修改方案后需要重算；宽表单独滚动。移除中介路径时移除依赖该边的间接路径。Excel 补充保存实际分析配置。

仍需注意：当前为 Windows 测试版，未实现项目保存/恢复；退出前须导出。AI 对话需配置服务，文献建议不能替代阅读全文。独立模拟默认逐个目标操作，尚未实现同时联合干预多个目标。元分析包原有介绍主体未修改。

## 0.6.0 中介与调节路径画布

中介调节页面改为“确认变量 → 安排路径”两步。先选择当前数据的实际变量；也可让 AI 根据你的说明填写 variables 并预选，变量含义不会由软件猜测。确认后生成交互画布，不自动添加假设路径。

- **连接路径**：点击起点，再点击终点。例如 X → M、M → Y、X → Y。可以安排串联中介、并联中介、直接效应和协变量路径。
- **指定调节**：先点击 W，再点击被调节的实线路径。橙色虚线连到路径中点，明确 W 调节的是哪条边；0.7.0 起以单个箭头指向被调节路径；必要主效应仍由计算引擎纳入。
- **移动变量**：拖动节点安排布局，也可用键盘方向键移动；支持自动排列和展开画布。移动位置不会改变统计路径。
- **间接效应**：从已连接的路径中勾选需要估计的链；存在调节时可勾选条件间接效应，默认取调节变量的原量尺均值及均值 ±1 SD，也可填写最多十个原量尺值。这里的默认值不是自动选择研究假设。
- **重新选择和删除**：取消变量或移除路径时，清理对应的调节、间接及条件间接效应；无关路径与布局保留。重复路径、自指、包含调节主效应的循环和未绑定路径的调节会被拦截。
- **同一份配置**：画布、路径文字配置和 AI 使用同一份规格。对话会附上当前画布草稿；AI 修改同一组变量的路径时保留已确认布局。更换数据版本或增加变量后重新确认。

当前支持数值观测变量的无环递归模型；分类变量须先明确数值编码，尚未提供潜变量测量模型或类别结局专用估计。规划图不展示未经计算的系数。模型的参数表会明确显示中心化交互项；报告回归路径图展示主效应，调节与条件效应以参数表和配置说明为准。

点击“开始本地分析”前确认使用当前数据。分析后点击“导出完整 Excel Word 与图片报告”，保留本次变量、路径、调节、间接效应与画布布局配置。科研绘图工作室继续提供实际参数及 95% 区间的 PNG、SVG、PDF。补充问答仍可跳过。退出前请导出；本版仍未提供项目保存/恢复。

## 0.7.0 界面与双模型更新

- **左键添加、右键删除路径**：确认变量后默认进入连接模式，左键点击起点和终点添加路径；右键点击回归路径直接删除。其绑定的调节、间接与条件间接效应同步清理；不影响其他路径。右键点击橙色调节箭头仅删除该调节关系。键盘选中路径后也可按 Delete 删除，下方保留移除按钮。
- **调节单箭头**：规划画布只画从 W 指向被调节路径的单个橙色虚线箭头。主效应仍正确进入模型，实际报告保留参数与配置。
- **三个可调宽窗口**：分析、AI 对话与文献辅助之间可以拖动分隔条，也可选中分隔条后按左右方向键调整。窗口会保留上次宽度，并在屏幕缩小时保留最小可用宽度。文献辅助每次启动默认隐藏；右上角“文献辅助 / 隐藏文献辅助”切换。
- **主力与检测模型**：主力调用固定分析工具，检测模型在每次回复后检查最新状态和本次真实工具记录。检测结论单独显示，不自动修改方案、删除数据或取消已跳过的步骤。检测失败保留主力回复并明确提示。0.7.1 起检测默认关闭，只有明确开启后才检查对话和写作建议；关闭时不会追加检测消息。第二模型会增加一次服务调用；检测意见不是正确性保证。
- **添加筛选规则**：问卷对话区“＋ → 添加问卷筛选规则”，支持 TXT、MD、JSON、DOCX。每份最多 2 MB / 30,000 字，最多五份，超限不截断。附件可展开核对文字并移除；导入不替换原数据，也不自动执行筛选。告诉 AI 先整理、检查或应用哪些规则；仍可跳过。完整报告保存附件原文，并明确实际执行情况以筛选审计为准。旧版的数据发送确认不覆盖新范围，升级后需重新勾选模型设置中的发送范围。

示例：添加规则文件后说“按附件整理计分和筛选配置，先核对列名和遗漏，让我确认再筛选”。DeepSeek 等服务使用其支持的 Chat Completions 兼容接口和实际模型 ID，服务地址与模型名称按提供方填写。若使用不同提供方，取消“使用主力服务的地址、接口和密钥”并配置检测服务。

## 0.7.1 检测模型改为可选

检测模型默认关闭，只配置主力模型即可保存、测试连接和使用。开启检测后才验证检测服务配置、调用检测模型；关闭后保留检测配置。旧版没有明确开关的配置升级后按关闭处理，可自行开启。
