## 本轮验证范围

- Node 自动测试27项通过，覆盖协议、隐私上下文、分页、状态重置、人类确认和新干预规格传递。
- 13组本地真实统计计算通过，包括中介调节、LPA、LCA、网络树、GGM比较与稳定性、HC/PC/GES/FCI、IDA、回归/分类森林及Ising。
- 新增分组切换和干预拒绝条件检查：缺少/不存在的目标、GGM结果重叠、非整数强度、CS与人类确认、上游替换失效。
- GGMNIRA外算实际运行：指定X，评估M/Y，完整X/M/Y/W网络保留，强度2，20次KL重抽样。
- NIRApost外算实际运行：预先构造的三节点纯两两作用合成分布，分别操作B1/B3，结果集合B2，强度1.5 SD，2次重复。此短测试只验证流程；不提供正式推断精度保证。
- 外算测试门槛使用明确标记的“使用者报告CS=.5”合成测试输入，**不是本轮估计得到的EI稳定性**。GGM报告中的KL CS是另外计算的指标。
- 对原五节点演示数据的NIRA前提阻断分支另行验证，保留诊断原因，不筛除数据或跳过前提来获得结果。
- 界面通过浏览器开发预览验证，安装版另外检查实际Electron和内置引擎启动。报告核对Excel与Word结构、规格、图片和表格。

## 使用边界

仍是未签名Windows测试版。项目保存/恢复尚未实现，退出前需导出。长时NIRA任务按要求在外部R环境运行，首次需安装依赖。当前逐个目标操作，不支持同时联合干预多个目标。AI模型兼容性测试不代表所有第三方供应商均已实测；连接需用户自己的服务配置。研究适用性仍需结合设计、测量、缺失与假设判断。

## 方法接口依据

- [NIRApost 固定修订](https://github.com/kingfly51/NIRA_post/tree/6231832736df7c693b630820729f73f64c30ec92)：调节检查、置换处理及模拟误差范围。
- [nodeIdentifyR 阈值扰动定义](https://github.com/JasperNaberman/nodeIdentifyR/blob/master/R/simulateResponses.R)：完整网络内单节点阈值按SD移动；本软件适配器只模拟所选目标并聚合所选结果。
- [GGMNIRA 固定修订](https://github.com/ywu6888/GGMNIRA/tree/9b3583a2e0f7af0422ea9291fd7060e2749264cb)：目标集合边际KL、操作强度和KL稳定性接口。
- [GGMNIRA预印本](https://arxiv.org/abs/2607.00915)：使用前核对正式发表状态；软件保留方法状态确认。
